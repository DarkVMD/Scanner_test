# Сроки годности — Flutter Android app

Офлайн-приложение для импорта справочника товаров из XLSX, сканирования штрихкодов и сохранения сроков годности.

## Что реализовано
- Импорт первых двух колонок первого листа XLSX: название, штрихкод.
- `.xls` распознаётся и сопровождается подсказкой о конвертации в `.xlsx`.
- Штрихкоды хранятся как строки; экспорт выполняется текстовыми ячейками.
- Сканирование EAN-13, EAN-8, Code-128 и QR камерой.
- Карточка товара с ручным вводом даты `ДД.ММ.ГГГГ` и календарём.
- Сохранение каждой записи в SQLite.
- История, удаление записи, экспорт всех записей в XLSX и системное меню «Поделиться».

## Как получить APK через GitHub Actions (без установки Flutter)

1. Скачайте архив проекта и распакуйте его.
2. На GitHub создайте новый пустой репозиторий (например, `shelf-life-scanner`).
3. Загрузите **содержимое папки `shelf_life_app`** в корень репозитория. В корне GitHub-репозитория должны быть видны `pubspec.yaml`, `lib/`, `README.md` и `.github/`.
4. Откройте вкладку **Actions** репозитория. Если GitHub предложит включить Actions, разрешите их.
5. При первой загрузке файлов в ветку `main` или `master` сборка запустится автоматически. Её также можно запустить вручную: **Actions → Build Android APK → Run workflow**.
6. Дождитесь зелёного статуса **Success**, откройте завершённый запуск и внизу страницы найдите **Artifacts**.
7. Скачайте `shelf-life-scanner-apk`, распакуйте ZIP — внутри будет `app-release.apk`. Это и есть установочный APK.

Workflow `.github/workflows/build-apk.yml` сам установит Flutter, создаст Android-проект, добавит разрешение камеры и соберёт APK в release-режиме. Сборка выполняется на серверах GitHub; Flutter и Android Studio на вашем компьютере не нужны.

> Если репозиторий приватный, артефакт будет доступен только пользователям с доступом к нему. GitHub хранит артефакт 14 дней.

## Сборка вручную (необязательно)

Требуются Flutter SDK (stable) и Android SDK. Из корня проекта:

```bash
flutter pub get
flutter create . --platforms=android --org com.example.shelflife
```

Добавьте в `android/app/src/main/AndroidManifest.xml` перед `<application>`:

```xml
<uses-permission android:name="android.permission.CAMERA" />
```

Затем выполните:

```bash
flutter build apk --release
```

APK появится в `build/app/outputs/flutter-apk/app-release.apk`.

## Важное замечание о ведущих нулях

Внутри приложения штрихкод хранится и сравнивается как `String`; в экспортируемом XLSX он записывается текстовой ячейкой. Но если исходный Excel уже сохранил EAN как число и удалил ведущий ноль, восстановить его однозначно невозможно только по числовому значению. Для надёжного импорта задайте второй колонке формат **Текстовый** до ввода/импорта штрихкодов. Если в исходном файле для числовых ячеек задан пользовательский формат вроде `0000000000000`, лучше предварительно преобразовать колонку в текст с сохранением отображаемых нулей.

## Текущие ограничения первой версии

- Справочник хранится в памяти приложения и очищается после полного закрытия процесса; записи сканирования сохраняются в SQLite. Повторный импорт справочника после запуска предусмотрен через главный экран.
- Импортируется первый лист, первые две колонки; первая строка-заголовок пропускается по распространённым названиям столбцов.
- Повторяющиеся штрихкоды в справочнике объединяются: используется первое вхождение.
- Повторные сканы разрешены и сохраняются отдельными записями.
